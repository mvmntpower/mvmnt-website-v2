## Built With

- Next.js 16
- React
- TypeScript
- Tailwind CSS
- Resend API
- Vercel

## Development

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Run the production server:

```bash
npm run start
```
